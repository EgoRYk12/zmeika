# 🐍 Змейка 2.0 
РЕЛИЗ 1.0

Моя первая игра на Python.

## 🎮 Что внутри
- Плавное управление змейкой (WASD / стрелки)
- Диагональное движение
- Яблоки дают +5 HP и +1 очко
- Боссы с HP-баром, которые стреляют
- Три сложности: лёгкий / средний / сложный
- Автонаведение пуль на босса
- Рукопашный удар (ПКМ) — когда очки кончились

## 🕹 Управление
- **WASD / стрелки** — движение
- **ЛКМ** — выстрел пулей (тратит 1 очко)
- **ПКМ** — рукопашный удар (не тратит очки)
- **P** — пауза
- **R** — рестарт
- **ESC** — меню

Установи файл и запускай
